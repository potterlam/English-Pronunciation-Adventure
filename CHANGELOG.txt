================================================================
  English Pronunciation Adventure - Change Log
================================================================

────────────────────────────────────────────────────────────────
  v1.0.0  |  September 2025  |  Initial Release
────────────────────────────────────────────────────────────────

[Core Game]
- Built monolithic single-file past-tense pronunciation game
- 4 game modes: Word Puzzle, Sword Slash, Multiple Choice, Boss Fight
- Word database with past-tense -ed words (/t/, /d/, /ɪd/)
- Sequential game progression with unlock system
- Basic story intro (4 scenes) with narrative text
- Cutscene transitions between each game chapter
- Bilingual support: zh-TW / English with toggle

[Audio]
- Background music (BGM) with loop
- Click, correct, wrong sound effects
- Text-to-speech (TTS) for word pronunciation

[Visual]
- Neon-styled dark theme UI
- Loading screen with spinner
- Game menu with card-based layout
- Ending screen with completion message


────────────────────────────────────────────────────────────────
  v2.0.0  |  January 2026  |  Major Restructure & Extension
────────────────────────────────────────────────────────────────

[Architecture]
- Complete restructure from monolithic file to modular architecture
  · js/app.js          – Game state & bootstrap
  · js/audio.js        – AudioManager class
  · js/screens.js      – ScreenManager class
  · js/translations.js – Bilingual translation data
  · js/game-system.js  – Central orchestrator
  · js/games/word-puzzle.js
  · js/games/sword-slash.js
  · js/games/multiple-choice.js
  · js/games/boss-fight.js
  · data/words.js      – Word database

[New Content: s/es/ies Mode]
- Added s/es/ies extension word dataset
- Separated -ed and s/es/ies into two selectable practice tracks
- Mode selector tabs added to game menu
- All 4 games adapted to read practiceMode (pastTense vs extension)

[Visual Enhancements]
- Character images for intro scenes, cutscenes, and games
  · player-sprite, warrior-sprite, wizard-sprite
  · pronunciation-king, hero-final, player-hypnotized
- Backdrop images for intro scenes (cave, cliff, wizard-lair, boss-arena)
- Per-game background images in game screens
- Extension color system for word categories
- Achievement / artifact collection panel with artifact images
- Ending video restored

[Game Improvements]
- Boss fight: added color hint toggle (🎨 ON/OFF)
- Sword slash: player sprite enlarged to 64x64
- Sword slash: fixed player position (bottom of arena)

[Audio Improvements]
- Lowered default volumes: BGM 30% → 15%, SFX 70% → 35%
